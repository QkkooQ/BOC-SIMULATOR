# Feature inventory

## Navigation

- Five primary tabs: home, accounts, assets, profile, and history.
- Secondary pages and modal overlays for cards, transactions, receipts, and profile
  editing.

## Account and card management

- Display aggregate assets and yesterday profit.
- Mask or reveal figures.
- Add, edit, and delete demo cards.
- Recalculate aggregate balances after changes.

## Transaction management

- Add income and expense records.
- Edit or delete an existing record.
- Display transaction receipts.
- Filter and summarize 2026 demo transactions.

## Local state

- Store the demo state under the `demo_bank_ui_v1` localStorage key.
- Restore the same state after reloading the page.

## Presentation constraints

- No backend, authentication, payment, or banking API is present.
- No request leaves the browser.
- No real institution or bank logo is used.
- All account data is clearly labeled as fictional.
